**Autor:** Aleksandra Djokic

## Opis projekta

Ovaj projekat demonstrira primenu nadgledanog masinskog ucenja na CTG podacima za klasifikaciju fetalnog zdravlja u tri klase:

- **Normal**
- **Suspect**
- **Pathological**

Kroz eksplorativnu analizu, predobradu podataka i poredjenje vise klasifikacionih modela, cilj je poboljsanje tacnosti i interpretabilnosti medicinskih predikcija.

Dataset: https://www.kaggle.com/datasets/andrewmvd/fetal-health-classification
